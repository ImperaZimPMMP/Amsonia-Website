Architecture

Rebuilt where it matters, kept where it works

The parts of PocketMine-MP that hold up stay. The parts that were held back by a decade of compatibility debt don't.

RS

Native acceleration

A persistent Rust worker pool handles pathfinding, chunk generation, and collision off the main thread — targeting a stable 20 TPS under load.

8.5

Modern PHP baseline

Built for PHP 8.4, validated against 8.5. Typed APIs, real stack traces on fatal errors, faster interpreter across the board.

λ

Polyglot plugins

Write plugins in PHP, Rust, Go, Python, or JavaScript. The core doesn't care which — it speaks a stable FFI contract.

1.0

Independent versioning

Amsonia resets to 1.0.0. No inherited version debt, no decade-old compatibility tax to carry forward.

VN

Vanilla fidelity

Native BDS-accurate world generation and a goal of full command parity with vanilla Bedrock — no missing pieces.

GH

Preserved lineage

Git history, original authorship, and licensing from PocketMine-MP remain intact and properly credited.

Roadmap

Three phases to independence

Identity first, ecosystem depth second, full cleanup last.

Phase 1

1.0.0

  • Identity & rebranding complete
  • pocketmine\ namespace preserved
  • PHP 8.4 baseline, 8.5 target
  • Native worker engine + FFI bridge
  • Entity system refactor
Phase 2

1.x

  • Multi-version protocol support
  • Native economy & permissions API
  • Async event system (Fibers)
  • Embedded JS / Python plugins
  • Gradual ecosystem renaming
Phase 3

2.0.0

  • Full API review
  • Deprecated naming removed
  • Amsonia\ namespace migration
  • Entity component system evaluation
