This isn't a goodbye.
It's a continuation.

PocketMine-MP shut down on July 9, 2026, after more than a decade of quietly running a huge share of the Minecraft: Bedrock server world. What follows isn't a product pitch. It's what happens next.

Why Amsonia exists

When the last maintainer stepped away, the code didn't disappear — it just stopped moving. Amsonia starts from that exact point: the same core, the same decade of decisions that got it right, kept moving instead of standing still.

It isn't a promise to preserve PocketMine-MP exactly as it was. Some of that no longer makes sense to carry forward unchanged. It's a promise that the parts worth keeping — the architecture, the community, the history — don't get thrown out just because the version number resets.

What carries forward

The Git history is untouched. Every commit, every original author, every license notice from PocketMine-MP stays exactly where it is. Amsonia isn't a rewrite pretending the past didn't happen — it's built on top of it, credited, in full.

PMMP's own farewell thanked the people who funded it, built it, and used it for more than ten years without asking for much in return. That debt doesn't disappear because the name on the door changed.

Amsonia is independently developed and does not claim endorsement from the former PocketMine-MP maintainers.

What's different

Practically, day one:

  • PHP 8.4 baseline, 8.5 target — instead of the older baseline PMMP was constrained to.
  • A native Rust layer handles pathfinding, chunk generation, and physics off the main thread.
  • Plugins aren't PHP-only anymore — Rust, Go, Python, and JavaScript all get a real path in.
  • Versioning resets to 1.0.0 — no decade of compatibility debt riding along for the sake of it.

Where it's headed

1.0.0

Identity first — becoming its own project without breaking what already works. pocketmine\ stays importable.

1.x

Ecosystem depth — multi-version protocol support, a native economy/permissions layer, plugins that run entirely outside PHP.

2.0.0

A full API cleanup, once the dust from 1.x has settled.

Try it

Existing pocketmine.yml configs are detected and migrated automatically on first launch.

$ curl -sSL get.amsonia.dev | bash
$ cd amsonia && ./start.sh
